# William — Portfolio Website

A professional portfolio website for **William**, Aspiring Investment & Policy Analyst, built with React 19, TypeScript, Vite, and Tailwind CSS. Styled after the Satner portfolio template aesthetic with clean typography, vector illustrations, and interactive project showcases.

---

## Features

- **Hero Section**: Ghost watermark lettering, tracked typography, direct CTAs (*Hire Me*, *Get CV*), and custom vector analyst desk illustration.
- **About Me Section**: "Let's Introduce About Myself" narrative, signature quote, quick biographical details, and sitting analyst vector graphic.
- **Core Skills & Services**: Investment Research, Data Interpretation, Political Analysis, and Strategic Thinking.
- **"What I'm Good At"**: Interactive competency explorer with real-world financial/policy context.
- **Projects & Experience**:
  - *Personal Investment Research*: Nigerian equities (banking stocks), risk management, and valuation metrics.
  - *Budget & Financial Planning*: Interactive budget model and savings optimization system.
- **Career Vision & Academic Focus**: Crawford University coursework (Political Economy, International Relations, Development Studies), target career sectors, and core guiding values.
- **Interactive Executive CV / Resume Modal**: Single-click printable format (`Ctrl + P` / `Cmd + P`) and plain-text copy.
- **Contact Section**: Direct communication channels, email clipboard action, and interactive inquiry form.

   ```bash

   ```

   ```bash

   ```

## How to Deploy on Vercel (1-Click)

1. Go to [Vercel](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New"** > **"Project"**.
3. Select your newly pushed GitHub repository.
4. Vercel will automatically detect **Vite** as the framework preset:
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
5. Click **"Deploy"**! Your portfolio will be live on a `*.vercel.app` domain within 60 seconds.
